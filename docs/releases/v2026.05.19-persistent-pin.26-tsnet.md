## Summary

This release keeps `.25` runtime behavior and improves only the built-in read-only tsnet Web page.

The self node card and peer hover popup now expose more of the already-protected `/tailscale` status fields so day-to-day diagnostics do not require copying raw JSON from the controller API.

## What Changed

- Self node metadata now includes allowed IPs, peer API URLs, primary routes, tags, exit-node flags, sharee-node state, expired state, created time, last write time, and last seen time when those fields are available.
- Peer hover popup now includes exit-node flags, sharee-node state, and expired state when available.
- All added fields are rendered from data already returned by the protected `/tailscale` API.
- Values continue to be HTML-escaped before rendering.

## Behavior Changes

Only the static read-only Web page changed.

- No backend behavior changes.
- No change to persistent pin behavior.
- No change to tsnet startup, registration, login-server fallback, gateway, mesh SOCKS, controller exposure, UDP behavior, DNS, rules, or groups.
- No change to `/tailscale` or `/tailscale/logs` API shape.
- No config, state-dir, or identity migration.
- `/tailscale/web` remains a static shell and continues to fetch runtime data through the protected controller API.
