## Summary

This release adds `-tailscale-wizard`, a one-shot CLI helper for registering or diagnosing the embedded tsnet node without starting the full mihomo runtime.

The wizard is intended for environments such as OpenWrt where the normal auth URL can be difficult to find in service logs. It reads only the `tailscale` section needed for registration, starts a temporary `tsnet.Server`, prints the auth URL when available, waits for authorization, and exits once the node has a tail IP.

## What Changed

- Added CLI flag `-tailscale-wizard`.
- Added `component/tsnet.RunWizard(homeDir, configFile)`.
- The wizard reads only `tailscale.login-server`, `tailscale.login-server-ip-fallbacks`, and `tailscale.state-dir` from YAML.
- Relative `state-dir` is resolved against `-d`, matching normal mihomo behavior.
- Missing `tailscale.state-dir` defaults to `tailscale`, matching the normal config default.
- The wizard uses the same state-dir lock and stable node name as the normal embedded tsnet runtime.
- The wizard prints state-file diagnostics before startup.
- The wizard prints the authorization URL from the IPN bus and waits up to `2m` for connection.
- The wizard exits `0` after successful connection and `1` on config, lock, startup, watch, or timeout failures.

## Behavior Changes

Normal mihomo runtime behavior is unchanged unless `-tailscale-wizard` is explicitly provided.

- No change to normal config load.
- No change to persistent pin behavior.
- No change to tsnet gateway, mesh SOCKS, controller exposure, UDP, DNS, rules, or groups.
- No change to `/tailscale`, `/tailscale/logs`, or `/tailscale/web`.
- The wizard does not start proxy listeners, controller listeners, mesh SOCKS, gateway SOCKS, rules, providers, geosite, or geoip.

## Usage

```bash
mihomo -d /etc/mihomo -f /etc/mihomo/config.yaml -tailscale-wizard
```

Expected flow:

1. Stop the normal mihomo service if it uses the same `tailscale.state-dir`.
2. Run the wizard with the same home/config paths.
3. Open the printed auth URL.
4. Authorize the node in Tailscale or Headscale.
5. Wait for the wizard to report success.
6. Start mihomo normally.
