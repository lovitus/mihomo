# Release Notes: `v2026.05.28-persistent-pin.28-tsnet`

## Release Identity

- release tag: `v2026.05.28-persistent-pin.28-tsnet`
- release family: persistent pin fork release with built-in tsnet feature
- release purpose: upgrade the embedded tsnet dependency to the latest official Tailscale stable release
- release branch: `pin-1.19.24merge-tailscale`
- parent branch: `persistent-pin-option-1.19.24merge`
- upstream base: `MetaCubeX/mihomo v1.19.24`
- upstream base commit: `a84724665eb7f989809abe463c05f5723bd24975`
- previous release: `v2026.05.20-persistent-pin.27-tsnet`
- previous release commit: `f3e8fe6b37838b5dd9e2a7f2108413117e3c8e89`

## Summary

This release keeps the `.27` tsnet feature surface and upgrades the embedded Tailscale module from `tailscale.com v1.68.2` to `tailscale.com v1.98.3`.

The main goal is to move the fork to the official current stable Tailscale code path, including the newer Android tsnet/router behavior that avoids the old Linux netlink route-table path on Android.

## What Changed

- `tailscale.com` is upgraded to `v1.98.3`.
- The root module now requires `go 1.26.3`, matching the Tailscale module requirement.
- GitHub Actions test and build workflows now use official Go `1.26.x` with `check-latest: true`.
- MetaCubeX custom Go download sources are removed from the tsnet branch workflows.
- Go `1.22` through `1.25` legacy test/build matrix entries are removed.
- `loong64-abi1` is paused until a MetaCubeX loongarch64 custom toolchain is available at Go `1.26.3` or newer.
- Go 1.26 vet failures from non-constant format strings are fixed.

## Compatibility

Mainstream build targets remain covered:

- Linux ordinary matrix
- Windows ordinary matrix
- macOS ordinary matrix
- FreeBSD ordinary matrix
- Android `386`, `amd64`, `arm`, and `arm64`

Removed legacy artifacts:

- Windows `go122`, `go123`, `go124`, and `go125` builds
- macOS Catalina and Big Sur compatibility builds tied to old Go toolchains
- Linux kernel 2.6.32 compatibility builds tied to Go 1.23
- current `loong64-abi1`

This release no longer promises Windows 7, macOS 10.13, macOS 10.15, macOS 11, or Linux kernel 2.6.32 compatibility from the removed legacy artifacts.

## Behavior Changes
