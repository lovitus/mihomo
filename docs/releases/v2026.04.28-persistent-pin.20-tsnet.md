## Summary

This release keeps `.19` runtime behavior and improves only the built-in read-only tsnet Web page. The peer table is now easier to scan when the tailnet has many nodes and no advertised routes.

The Web shell remains static and public. Runtime data is still fetched only through the controller-protected API.

## What Changed

- Peer search now includes state labels and peer tags in addition to names, OS, tail IPs, and routes.
- The IP column is sortable using the first sorted tail IP, with IPv4 addresses sorted numerically.
- The Routes column is hidden automatically when the current filtered peer list has no primary routes.
- Direct peer connections show both `direct` and the concrete current address in the Relay column.
- The peer table element now has a stable ID for table-level UI state.

## Behavior Changes

No backend behavior changes.

- No change to tsnet startup, gateway, mesh SOCKS, controller exposure, UDP behavior, or status API authentication.
- No change to the static-shell safety contract for `/tailscale/web`.
- No config, state-dir, or identity migration.
